# Analysis-and-design

CS 300: Data structured and algorithms:
This contains artifacts that show my skill to analyze data structures, evaluating algorithm efficiency and design software solutions that are scalable, maintainable and effective. Developing a course capable of storing, searching, and displaying the academic course info while managing the prerequisites. 

Project 1: Data Structure Analysis:
In this I evaluate vectors, has tables, and binary search trees to determine the effectiveness for storing and getting the course data. The analysis compares the runtime, memory, and overall performance to identify the most suitable solutions. 

Project 2: Course Planner Application:
I used C++ ;pading course data from a file, storing the information in an appropriate data structure and showing courses in alphanumeric order. The app also supports searches for individual courses and shows the prerequisite info. 

Reflection:
What was the problem you were solving in the projects for this course?
The main objective of this was to make and implement an academic course advising system capable of efficiency storing, organizing and retrieving information. The challenge was evaluating different data structures and selecting a solution that would provide the best performance while maintaining an accurate prerequisite relationship and helping support sorted output of data. 

How did you approach the problem? Consider why data structures are important to understand.
I approached the problem first analyzing the operations requirements of the advising system and then comparing the strengths and limitations of vectors, hash tables, and binary search trees. Understanding the data structure is key because they directly affect the runtime, memory, and scalability. By checking the time complexity of common operations like insertions, searching, and traversal. I was able to an informed design decision solely based on performance rather than simple convenience. 

How did you overcome any roadblocks you encountered while going through the activities or project?
During the developing process I encountered challenges with data parsing, prerequisite relationship and maintaining proper course ordering. To address the issues, I apply a systemic debugging strategy that includes increment testing, code tracing, and validation of program outputs against expected results. Dividing complex tasks into smaller components allowing me to isolate problems efficiency and implement reliable solutions. 


How has your work on this project expanded your approach to designing software and developing programs?
This project strengthened my understanding of software design by demonstrating the importance of evaluating requirements before implementation. Rather than focusing exclusively on creating a functional program, I learned to analyze multiple design alternatives and justify my decisions using algorithmic analysis and performance considerations. As a result, I now place greater emphasis on planning, efficiency, scalability, and long-term maintainability during the software development lifecycle.

How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?
This project reinforced the importance of writing clean, modular, and well-organized code. I improved my ability to separate responsibilities into focused functions, implement meaningful naming conventions, and develop reusable program components. Additionally, I learned to design software with future modifications in mind, making applications easier to maintain, debug, and extend as requirements evolve.
